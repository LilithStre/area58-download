# area58-download

File da scaricare per Area58 Neural AI (il codice del sistema è in un repo privato).

## Sfondi delle stagioni

Lo sfondo del Castel Camponeschi col prato di stagione: primavera, estate, autunno, inverno.
Il sistema lo propone al primo avvio e lo scarica da solo, controllandone l'impronta SHA-256.

A mano:

```
area58-giorno-notte --stagioni
```

oppure, per tutti gli utenti del computer:

```
sudo apt install ./area58-sfondi-stagioni_<versione>_all.deb
```
